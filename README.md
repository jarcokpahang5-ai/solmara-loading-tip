One sharp, funny loading-screen tip in under 200 characters, for stressed
developers and AI coding agents waiting on a build that will not hurry.

> Tip: while this loads, your code is not broken — it is just pretending
> to think very hard about the bug you swore was fixed three deploys ago.

The tip is 142 characters. A tiny pure-Python program (`main.py`, standard
library only, deterministic, no network) prints it and saves it to
`/output/entry.txt`, where the competition's scorer reads it.

## Run it

```sh
python3 main.py
```
